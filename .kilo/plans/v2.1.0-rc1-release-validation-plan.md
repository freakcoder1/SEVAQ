## Additional Pre-RC Checks

### Health Endpoint Verification
The `/health` endpoint (via `HealthService`) checks:
- Database connectivity (`database`)
- Memory health (`memory_heap`, `memory_rss` with thresholds)
- Active workers count (`workers`)
- Services availability (`services`)

Expected response format:
```json
{
  "status": "ok",
  "info": {
    "database": { "status": "up" },
    "memory_heap": { "status": "up" },
    "memory_rss": { "status": "up" },
    "workers": { "status": "up", "activeWorkers": N },
    "services": { "status": "up", "totalServices": N }
  }
}
```
